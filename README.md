# Shopify Theme Customization (Dawn)

Custom Shopify storefront theme built on **Shopify Dawn 15.4**, with customized Liquid sections, snippets, styles and JavaScript for cart, product and collection pages.

## What's customized
- Liquid sections and snippets for the home, collection and product templates
- Component styles (cards, cart drawer, mega menu, facets, slideshow)
- Cart drawer and cart notification behaviour
- Theme settings in `config/settings_schema.json`

## Tech stack
Shopify · Liquid · JavaScript · CSS · Shopify CLI

## Work on the theme
```bash
npm install -g @shopify/cli
shopify theme dev --store your-store.myshopify.com
```
Push changes with `shopify theme push`.
